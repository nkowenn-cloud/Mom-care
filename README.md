# ตารางดูแลตัวเองของแม่

เช็คลิสต์ประจำวันสำหรับแม่ (โรคหลอดลมโป่งพอง) มีรายการดื่มน้ำ ฝึกไอ 3 เวลา อาหาร 3 มื้อ Once Pro 3 แก้ว ออกกำลังกาย และบันทึกน้ำหนัก ข้อมูลส่งไปเก็บใน Google Sheet ได้

## ไฟล์
- `index.html` — ตัวแอพ เปิดผ่าน GitHub Pages
- `Code.gs` — สคริปต์สำหรับ Google Apps Script รับข้อมูลลงชีต

## ตั้งค่า Google Sheet (ครั้งเดียว ทำในคอมจะง่ายกว่า)
1. สร้าง Google Sheet ใหม่
2. เมนู Extensions > Apps Script ลบโค้ดเดิมออก วางโค้ดจาก `Code.gs` แล้วกด Save
3. Deploy > New deployment > เลือกประเภท Web app
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด Deploy แล้วอนุญาตสิทธิ์ (ถ้าขึ้นคำเตือน ให้กด Advanced > Go to … )
5. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

## เชื่อมแอพกับชีต
1. เปิดแอพ เลื่อนลงล่างสุด กด **ตั้งค่าการส่งข้อมูล**
2. วางลิงก์ Web app แล้วกด **เชื่อมต่อ**
3. กด **คัดลอกลิงก์ส่งให้แม่** แล้วส่งให้แม่ทาง LINE ให้แม่กดเปิด 1 ครั้ง จากนั้นกด "เพิ่มไปยังหน้าจอโฮม"

ข้อมูลจะขึ้นในแท็บ "บันทึก" ของชีต ทุกเครื่องที่เชื่อมลิงก์เดียวกันจะเห็นข้อมูลชุดเดียวกัน

## หมายเหตุ
- ลิงก์ Web app ใส่ไว้ใน `index.html` แล้ว (ตัวแปร `DEFAULT_SYNC`) เปิด nkowenn-cloud.github.io/Mom-care/ ก็ซิงค์ได้เลย ถ้าเปลี่ยนชีตให้แก้ค่านี้
- ถ้าเน็ตหลุด แอพยังติ๊กได้ตามปกติ แล้วจะส่งข้อมูลเองเมื่อเน็ตกลับมา
- ชีตมีไว้ดูข้อมูล ถ้าแก้ข้อมูลในชีตตรงๆ แอพอาจเขียนทับได้
- ถ้าแก้ไข `Code.gs` ภายหลัง ให้ Deploy > Manage deployments > แก้ไข > Version: New version เพื่อให้ลิงก์เดิมใช้งานได้ต่อ

## แจ้งเตือนทาง LINE เมื่อแม่ยังไม่ติ๊ก
สคริปต์จะเช็กชีตตอน 10 โมง บ่าย 2 และ 1 ทุ่ม (คลาดได้ ±15 นาที) แล้วส่ง LINE บอกรายการที่ยังไม่ได้ติ๊ก ถ้ารอบ 1 ทุ่มทำครบแล้วจะส่งคำชมแทน

1. สร้าง LINE Official Account ฟรีที่ manager.line.biz ตั้งชื่อเช่น "ดูแลแม่"
2. ใน OA Manager: ตั้งค่า > Messaging API > เปิดใช้งาน
3. ที่ developers.line.biz เลือก channel ของ OA นี้ > แท็บ Messaging API > Channel access token (long-lived) > Issue > คัดลอก
4. ให้แม่แอดเพื่อน OA นี้ (สแกน QR จาก OA Manager) ถ้าอยากได้ข้อความเตือนด้วย ให้แอดตัวเองด้วย
5. ใน Apps Script: วางโค้ด `Code.gs` ใหม่ทับ > Project Settings > Script Properties > เพิ่ม `LINE_TOKEN` = token ที่คัดลอก
6. เลือกฟังก์ชัน `testLine` > Run (อนุญาตสิทธิ์) ถ้าข้อความทดสอบเข้า LINE แล้ว ให้ Run `setupReminders` 1 ครั้ง

แนะนำให้ปิด "ข้อความตอบกลับอัตโนมัติ" ใน OA Manager ด้วย แม่จะได้ไม่งงถ้าพิมพ์ตอบ
เปลี่ยนเวลาเตือนได้ที่ `REMIND` ใน `Code.gs` แล้ว Run `setupReminders` ใหม่
บัญชีฟรีมีโควตาข้อความต่อเดือนจำกัด สคริปต์เตือนไม่เกินวันละ 3 ครั้ง และส่งเฉพาะเมื่อมีรายการค้าง ข้อความนับตามจำนวนคนที่แอด OA
